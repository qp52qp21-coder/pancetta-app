# アプリアイコンを朱赤にする

2026-09-17

## きっかけ

臙脂 `#8C2F2A` の地のアイコンが、ホーム画面で「渋すぎる」。特に暗い壁紙の上で沈んで見える。
4案（今の臙脂 / 明るい紅 / 朱赤 / 生ハム色）を暗い壁紙・明るい壁紙の上で見比べ、**朱赤**に決めた。

## 決めたこと

### 色（絵の形は変えない）

| 部分 | 旧 | 新 |
|---|---|---|
| 地・赤身の渦 | 臙脂 `#8C2F2A` | 朱赤 `#D2412F` |
| 外皮 | 塩 `#C8BFA9` | 明るい塩 `#E8D9BD` |
| 脂 | 生成り `#F6EEE0` | 明るい生成り `#FFF8EC` |

外皮と脂も明るくするのは、朱赤の地に対して旧の色だとくすんで見えるため。
赤身の渦を地と同じ色にする仕組み（脂の面に地が透けて見える）はそのまま。

### 完成の印も朱赤に揃える

アーカイブのカード右上の「完成の印」（`index.html` の `<symbol id="pancetta-mark">`）はアイコンと同じ絵なので、同じ朱赤にする。
朱肉で押した「朱印」の見立てになり、和モダンの画面になじむ。

### アプリ本体の臙脂は変えない

輪・★・完成予定日・減少率などの臙脂 `#8C2F2A` はそのまま。
DESIGN.md の「差し色は臙脂1色だけ」を「**臙脂が差し色。ただしアイコンと完成の印だけは朱赤**」に改める。

## 作業

1. 旧アイコン（`icon-*.png` 4枚と `icon-source.svg`）を `icons-history/2026-09-17-enji/` に控える
2. `icon-source.svg` の色とコメントを差し替える
3. Edge で 192 / 512 を書き出し、any と maskable の4枚を置き換える（元絵は中央66.7%の円に収まっているので同じ画像でよい）
4. `index.html` の `pancetta-mark` の色を差し替える
5. `DESIGN.md` と `CLAUDE.md` の記述を更新する
6. 確認：書き出した PNG を目視（色・丸い切り抜きで欠けない）。localhost でアーカイブの完成の印を画面で確認
7. コミットして push。GitHub Pages と Cloudflare Pages の両方で新しいアイコンが配信されていることを確認

## 注意

Android はホーム画面のアイコンを保持するため、push 後もすぐ変わらないことがある。
その場合はホーム画面のアイコンを外して「ホーム画面に追加」し直す（記録は消えない）。
