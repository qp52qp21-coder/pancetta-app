## 2. 通知機能

### ぶつかった制約

最初に判明したのは、**このアプリの構成のままでは本物のプッシュ通知は作れない**ということだった。

Webのプッシュ通知（Web Push）は、時刻になったら通知を送りつける**サーバー**が必須になる。
本アプリはGitHub Pages上の静的サイトで、HTMLを配るだけ。時間を数えて通知を送る役がいない。

### 検討した3つの案

| 方式 | 判断 | 理由 |
|---|---|---|
| 端末カレンダーへの予定登録 | **採用** | カレンダーアプリの通知は確実に鳴る。費用ゼロ、アカウント追加なし |
| PWAのバックグラウンド機能（Periodic Background Sync） | 不採用 | Chromeの裁量で発火せず「来るはずの通知が来ない」事故が起きる。iPhoneは非対応 |
| アプリ起動時の強調表示 | **採用（補助）** | 見落とし・登録忘れに対する保険として |

「追加費用・追加登録なしで最善の方法」という条件と、
利用端末がAndroid（Google Pixel）であることから、
**カレンダー登録を主、起動時のお知らせを従**とする構成に決めた。

### 作ったもの

**① カレンダーへの通知登録**

仕込みカードの「🔔 通知をカレンダーに登録」ボタンから、2件の予定を登録できる。

| 予定 | 日付 | 時刻 |
|---|---|---|
| 🥓 {仕込み名}：スパイスをまぶす日 | 仕込み開始 + 塩漬け日数 | 朝5:00 |
| 🥓 {仕込み名}：熟成完了・味見の日 | 仕込み開始 + 全日数 | 朝5:00 |

- ボタンを押すとGoogleカレンダーが**内容入力済み**で開くので、「保存」を押すだけ
- 予定の説明欄には配合・仕込み開始日・スパイスメモが入る
- 新規仕込みの登録直後にこの画面が自動で開く（設定忘れの防止）
- 一度登録するとボタンが「🔔 通知は登録済み」に変わる

**② 起動時のお知らせカード**

「熟成中」タブの最上部に、その日に該当する仕込みだけを表示する。

- 塩漬け終了当日 → 「今日からスパイス工程です」
- 完成予定日当日 → 「今日が完成予定日です」
- 完成予定日を過ぎている → 「熟成期間が◯日過ぎています」
- 該当なしの日は何も表示しない

### 残っている制限

通知が鳴る時刻は**Googleカレンダー側の設定**に従う。既定は「予定の30分前」なので、
5:00の予定だと4:30に鳴る。ちょうど5:00にしたい場合は、
カレンダーで通知を「0分前」に変更する必要がある。
（予定作成URLでは通知時刻を指定できないため、アプリ側では制御できない）

## 3. 豚さんマスコット

絵文字🐷ではなく、**自前のSVGイラスト**として描いた。
理由は、絵文字だと端末ごとに絵柄と色が変わってしまい、
このアプリの「配色は3色のみ」というルールから外れてしまうため。

使った色は既存の色だけ — 淡いローズ（体）、ローズ（輪郭）、濃茶（目）、生成り（鼻）。

表情は3種類を用意し、場面で使い分けている。

| 場所 | 表情 |
|---|---|
| ヘッダーのロゴ | `calm` おだやかな顔 |
| 熟成中が空のとき | `sleep` 目を閉じて「z z」 |
| アーカイブが空のとき | `happy` 目が ^ ^ ・キラキラ付き |
| 完成おめでとうモーダル | `happy`（大きめ） |
| アーカイブの各カード | `happy`（小さく名前の左に） |

アプリアイコン（`icon-192.png` / `icon-512.png`）も、
この同じ豚さんをブラウザで描き出してPNG化したもの。
絵柄が完全に一致するので、ホーム画面とアプリ内で印象がそろう。

### つまずいた点：Pixelで豚さんが小さく表示された

ホーム画面に追加したところ、**白い丸の中に小さく豚さんが置かれる**状態になった。

原因は、`manifest.json` のアイコンに `"purpose": "maskable"` の指定が無かったこと。
Androidはアイコンを丸くくり抜くため、maskable指定が無いアイコンをChromeが受け取ると
「くり抜いて絵が切れたら困る」と判断し、安全策として白い丸の中に縮小して配置する。

対策として、maskable専用のアイコンを別に用意した。

- 背景の生成りを**四隅まで敷き詰める**（白い丸が出ないように）
- 豚さんを**中央66.7%の円**に収まる最大サイズで配置
  （Pixelの丸マスクはこの円の外側を切り落とすため、これより大きいと耳が切れる）

作業中は、実際に円形マスクをかけた状態を画面に並べて確認し、
耳が切れないぎりぎりの大きさを決めた。結果、ホーム画面で豚さんが大きく表示されるようになった。

**注意**: アイコンはホーム画面に追加した時点で端末に保存されるため、自動では更新されない。
更新するには、古いショートカットを削除してから「ホーム画面に追加」をやり直す。
記録データはブラウザ内の別の場所にあるので、追加し直しても消えない。

## 4. 検証

テストの仕組みが無いプロジェクトなので、
`index.html` の中身をそのまま読み込んで動かす検証スクリプトを書き、
実際のコードに対して確認した。

| 分類 | 項目数 | 結果 |
|---|---|---|
| お知らせカードの条件分岐 | 5 | 合格 |
| 端の条件（スパイス期間0日・開始日が未来・完成済み） | 3 | 合格 |
| GoogleカレンダーURLの生成 | 5 | 合格 |
| 既存データとの互換性 | 2 | 合格 |

加えて、ローカルにサーバーを立てて実際の画面でも確認した。
スマホ幅（375px）でのレイアウト、通知モーダル、新規登録直後の自動表示、
「登録済み」への切り替わりまで、すべて意図どおり動作した。

この過程で「トーストが通知モーダルの注意書きに重なる」という表示の問題が見つかり、
トーストの重なり順をモーダルより下げることで修正した。

## 5. 使い方（スマホでの設定手順）

1. https://qp52qp21-coder.github.io/pancetta-app/ を開く
2. 「＋ 新規仕込み」で仕込みを登録する
3. 直後に通知登録の画面が自動で開くので、2つの日付ボタンをそれぞれ押す
4. Googleカレンダーが開いたら **「保存」** を押す（2件とも）
5. （任意）カレンダー側で通知を「0分前」に変えると、ちょうど朝5:00に鳴る

**アイコンを豚さんにするには**、ホーム画面の古いアイコンを一度削除し、
上のURLを開き直してから「ホーム画面に追加」をやり直す。
アイコンは追加した時点で端末に保存されるため、自動では更新されない。
